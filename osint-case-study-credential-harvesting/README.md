# OSINT Case Study: Darknet Credential Harvesting Operation

A structured intelligence case study based on sanitized darknet forum content, focused on credential harvesting activity, actor clustering, ATT&CK mapping, and final reporting.

## Why this repo exists

This project demonstrates investigative skill, OSINT methodology, and intelligence writing. It is designed to look like a practical case study rather than a simple code sample.

## Included

- sanitized darknet forum posts
- methodology
- extracted signals
- actor clustering
- ATT&CK mapping
- final intelligence report

## Repo layout

- `data/` — sanitized source material
- `analysis/` — extraction and clustering notes
- `visuals/` — timeline / relationship / signal visuals
- `reports/` — final intelligence report drafts

## Review guide
