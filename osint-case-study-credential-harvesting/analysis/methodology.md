# Methodology

## Scope
This case study uses sanitized darknet forum content to demonstrate an OSINT workflow for credential-harvesting analysis.

## Workflow
1. Collect sanitized source text
2. Extract high-signal terms and behavior references
3. Cluster actors by repeated language and role
4. Map behaviors to ATT&CK
5. Summarize findings in a final intelligence report

## Confidence model
- low: single mention with weak context
- medium: repeated references to tooling or access
- high: recurring role behavior plus infrastructure or monetization pattern
