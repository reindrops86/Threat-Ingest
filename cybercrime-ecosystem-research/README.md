# Cybercrime Ecosystem Research

A research-focused repo analyzing one cybercrime ecosystem with a structured intelligence write-up, supporting visuals, TTPs, infrastructure, and trends.

## Focus ecosystem

Ransomware affiliates

## Why this repo exists

This project shows research depth. It is designed to look like the kind of structured ecosystem analysis a senior threat-intelligence researcher would publish.

## Included

- structured analysis
- visuals
- TTPs
- infrastructure
- trends

## Repo layout

- `analysis/` — main research write-up
- `visuals/` — charts and visual notes
- `notes/` — supporting observations

## Review guide

1. `README.md` — overview
2. `analysis/` — core report
3. `visuals/` — graphic-ready content
4. `notes/` — supporting research notes
