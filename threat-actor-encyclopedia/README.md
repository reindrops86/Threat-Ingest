# Threat Actor Encyclopedia

A compact intelligence-writing repo that demonstrates actor profiling, TTP documentation, infrastructure tracking, campaign timelines, and attribution notes.

## Purpose

This repo shows intelligence writing skill, not just technical implementation. It is designed to read like an analyst-friendly knowledge base for threat actor research.

## Included

- actor profiles
- TTP summaries
- infrastructure notes
- campaign timelines
- attribution notes

## Repo layout

- `profiles/` — actor profiles
- `campaigns/` — campaign timelines and summaries
- `notes/` — attribution and tradecraft notes

## Review guide

1. `README.md` — overview
2. `profiles/` — actor-level documentation
3. `campaigns/` — campaign timelines
4. `notes/` — analysis notes and attribution reasoning

## Portfolio value

This project demonstrates threat-intelligence writing, source organization, and actor analysis discipline.
